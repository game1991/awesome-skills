Unique Value

Auto Memory 做不到的三件事

LFE 不重复内置能力，只做内置体系没有的独有价值

🚀

经验 → SKILL.md

Auto Memory 只写入 MEMORY.md 规则。LFE 能委托 writing-skills 用 TDD 流程生成完整的 SKILL.md，包含触发条件、核心流程、测试场景和约束条件。这是内置体系从未实现的能力。

🔧

重复操作 → 脚本/MCP

检测到重复执行的可自动化操作时，LFE 生成脚本或 MCP 服务提案，经用户确认后实现。Auto Memory 会"记住你经常做这件事"，但不会主动帮你自动化它。

📈

规则 → Skill 升级

当同一主题积累 3+ 条 MEMORY.md 规则时，LFE 提议升级为 SKILL.md。AutoDream 会合并冗余，但不会主动将分散的规则提炼为结构化的 Skill 流程。

Quick Start

5 分钟上手

安装后立即可用，无需配置

① 安装 Skill

运行 bash install.sh，30 秒完成。零必需依赖，开箱即用。

② 像平时一样对话

当你重复某个操作时，LFE 检测到 pattern-catalog 中的匹配项，自动提示复用已有 Skill。

③ 手动触发升级

说 "learn from this" 或 "make a skill for this"，LFE 将当前经验路由到合适的产物类型。

④ 确认产物

LFE 会通过交互确认生成什么（Skill / 脚本 / 规则），你完全掌控，不会自动写入任何内容。
