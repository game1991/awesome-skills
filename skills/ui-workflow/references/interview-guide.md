# 访谈问题库（Phase 1 使用）

## 提问纪律

- 全部走 AskUserQuestion，一次最多 2 个相关问题。
- **快速模式优先**：能推断的先给默认值再确认（"我按 X 设计了，对吗？"），
  只有存在真实分叉（2-3 个选项各有可能）才开放式提问。
- 每轮答复立即写入 pages-map.md，再问下一轮。
- 用户答不上的问题：不要追问，选保守默认值并记录"该决策为模型默认，未确认"。

## L1 产品层（每个产品问一轮）

1. 产品用途一句话？主要给谁用（运维/开发/业务/管理员）？
2. 页面清单：预估有哪些页面？生成页面地图（列表如下）请用户增删。
3. 页面流转：每页的入口、跳转目标、传递参数（query/params）。
   格式：`列表页 --点击行--> 详情页(?id=)`。
4. **横向问项（一次问完，multiSelect 或一组）**：
   - 是否嵌入现有系统框架？（有全局导航/主题 → 原型不做外壳，只做页面主体）
   - 目标最小视口？（默认 1280px；有半屏场景 → 1200px）
   - 暗色模式？（默认：不需要/后续）
   - i18n？（默认：纯中文硬编码）
5. 参照物：有想对齐的现有系统或产品吗？（链接/截图/系统名）

## L2 页面层（逐页走，快速模式默认值已按类型预填）

### 页面类型判断（先确认）
列表页 / 表单页 / 详情页 / 仪表盘 / 混合。类型决定状态矩阵与组件选型。

### 必问四件套
- **字段清单**：展示哪些字段？按重要度排序（影响列宽/折叠策略）。
- **操作清单**：行操作 + 批量操作 + 页级操作。
- **权限/多角色**：有几种角色？哪些操作/字段按角色显隐或禁用？
  （默认：单角色全员可见——若用户提到"管理员才能删"等立即升级为多角色处理）
- **数据量级**：列表预期条数？<500 → 前端分页；500-1万 → 服务端分页+筛选；
  >1万 → 考虑虚拟滚动/导出。表单字段数 >20 → 分步向导。

### 异常流四问（每页过一遍，未提及用默认）
- 加载态：骨架屏 or loading？（默认：表格骨架屏）
- 错误态：请求失败如何反馈？（默认：页面级 Alert + 重试按钮）
- 空态：无数据时展示什么？（默认：组件库标准空态插图 + 主操作引导）
- 危险操作：哪些操作需要二次确认？（默认：删除/批量操作 → Popconfirm）

### 数据契约
- 有接口文档/swagger → 索取，提炼字段名与分页协议写入 api-contract.md。
- 没有 → 与用户确认三件事：字段命名风格（默认 camelCase）、
  分页协议（默认 `{list, total, page, pageSize}`）、包裹结构。
- 产出 `ui-prototype/api-contract.md`（TS interface 形式）。

## L3 视觉层（每页或每类页面问一轮）

- 给 2-3 个布局选项，附 ASCII 线框。常见分叉：
  - 导航：左侧导航 vs 顶部导航（若嵌入现有框架，此问跳过）
  - 列表密度：紧凑 vs 标准 vs 宽松
  - 筛选区：顶部展开 vs 收起为高级搜索
  - 详情页：左描述右表 vs 分组 Tab
- ASCII 线框规范：用 `┌─┐│└┘` 画区块级（导航/筛选/表格/分页），不画到控件级。

## pages-map.md 页面区块固定 schema

```markdown
## 页面：<名称>（类型：列表页）
- 路由：/xxx；入口：侧栏菜单；跳转：详情页 ?id=
- 字段：名称(text) / 状态(tag: 成功绿-失败红) / 时间(datetime) ...
- 操作：行[编辑, 删除(危险确认)] 批量[导出] 页级[新增]
- 权限：单角色（删除仅管理员 → 角色切换器 mock admin/viewer）
- 数据量级：~1万条 → 服务端分页 + 顶部筛选
- 状态矩阵：loading=骨架屏 / empty=标准空态 / error=Alert+重试
- 布局决策：左侧导航 / 标准密度 / 顶部筛选展开
- deviation（与默认形态不一致处，Phase 3 迭代中累积）：
```
